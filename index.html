NỀN TẢNG

⚡ Điện áp — Dòng điện — Điện trở

Điện áp V là chênh lệch điện thế, dòng điện I là dòng điện tích, điện trở R cản trở dòng điện.

Định luật Ohm: V = I × R

  • V = I × R
  • I = V / R
  • R = V / I
NỀN TẢNG

🔌 DC và AC

DC có chiều điện áp/dòng điện theo một hướng quy ước. AC thay đổi theo thời gian và thường gặp trong hệ thống điện xoay chiều.

Khi học Arduino

Arduino chủ yếu làm việc với tín hiệu và nguồn DC mức thấp. Không được đưa điện áp lưới vào chân GPIO.

NỀN TẢNG

🔗 Nối tiếp và song song

Nối tiếp: Rt = R1 + R2 + ...

Song song 2 điện trở: Rt = (R1×R2)/(R1+R2)

Hiểu hai kiểu này rất quan trọng trước khi học mạch cảm biến.

ĐIỀU KHIỂN

🎚️ Analog và Digital

Digital thường biểu diễn các mức logic như LOW/HIGH. Analog biểu diễn một đại lượng biến thiên trong một khoảng.

  • Digital: nút nhấn, công tắc, relay logic.
  • Analog: biến trở, cảm biến nhiệt độ analog.
  • PWM: tạo tín hiệu xung để điều khiển độ sáng/tốc độ trong nhiều ứng dụng.
ĐIỀU KHIỂN

🔄 Feedback và vòng điều khiển

Một hệ điều khiển thường có: giá trị đặt → bộ điều khiển → đối tượng → cảm biến → phản hồi.

Đây là nền tảng để sau này học PID, PLC và hệ thống tự động hóa.

ARDUINO — BÀI 01

💡 Blink — LED nhấp nháy

Bài đầu tiên để hiểu setup(), loop(), pinMode(), digitalWrite() và delay().

Arduino C/C++
const int LED_PIN = 13;\n\nvoid setup() {\n  pinMode(LED_PIN, OUTPUT);\n}\n\nvoid loop() {\n  digitalWrite(LED_PIN, HIGH);\n  delay(500);\n  digitalWrite(LED_PIN, LOW);\n  delay(500);\n}
ARDUINO — BÀI 02

🔘 Nút nhấn điều khiển LED

Dùng INPUT_PULLUP để giảm số linh kiện khi học nguyên lý.

Code
const int LED_PIN = 13;\nconst int BUTTON_PIN = 2;\n\nvoid setup() {\n  pinMode(LED_PIN, OUTPUT);\n  pinMode(BUTTON_PIN, INPUT_PULLUP);\n}\n\nvoid loop() {\n  bool pressed = digitalRead(BUTTON_PIN) == LOW;\n  digitalWrite(LED_PIN, pressed ? HIGH : LOW);\n}
ARDUINO — BÀI 03

🎚️ PWM LED

Dùng analogWrite() để thay đổi duty cycle trên chân PWM phù hợp.

Code
const int LED_PIN = 9;\n\nvoid setup() {\n  pinMode(LED_PIN, OUTPUT);\n}\n\nvoid loop() {\n  for (int value = 0; value <= 255; value++) {\n    analogWrite(LED_PIN, value);\n    delay(5);\n  }\n}
ESP32

📡 ESP32 khác Arduino ở đâu?

  • ESP32 có kết nối Wi‑Fi/Bluetooth tích hợp.
  • GPIO và mức điện áp cần được kiểm tra theo đúng board đang dùng.
  • Arduino IDE có thể dùng để lập trình ESP32 sau khi cài board package.

Mục tiêu: sau khi hiểu Arduino, chuyển sang IoT.

PLC — BÀI 01

🏭 PLC là gì?

PLC là bộ điều khiển logic lập trình dùng trong tự động hóa công nghiệp. Một vòng cơ bản: đọc input → chạy chương trình → cập nhật output.

Chu trình quét PLC

  1. Đọc trạng thái Input.
  2. Thực thi chương trình.
  3. Cập nhật Output.
  4. Lặp lại.
LADDER

🔘 Start / Stop Motor

Logic kinh điển: nút Start đóng mạch, Stop ngắt mạch, tiếp điểm tự giữ giữ motor chạy.

Logic giả lập
|----[/STOP]----+----[START]----+----( MOTOR )----|\n|               |               |\n|               +----[MOTOR]----+                 |
LADDER

🚨 Đèn cảnh báo

Nếu cảm biến lỗi ON thì đèn cảnh báo ON. Đây là dạng logic rất cơ bản để bắt đầu.

Logic
|----[ SENSOR_ERROR ]----( ALARM )----|

BÀI TẬP

📝 Bài tập PLC cho Phúc

  1. Thiết kế logic Start/Stop cho motor.
  2. Thêm cảm biến quá tải.
  3. Nếu quá tải → Motor OFF + Alarm ON.
  4. Thêm nút Reset Alarm.
  5. Sau đó chuyển logic sang Ladder trên phần mềm PLC mà trường sử dụng.

Mục tiêu: không chỉ đọc code, mà tự vẽ logic trước khi lập trình.
